# Third-party notices and sources

- `tf-demo-parser` / demostf parser: <https://codeberg.org/demostf/parser>. The bundled parser source declares `MIT OR Apache-2.0` in `Cargo.toml`.
- HLAE / AdvancedFX AfxHookSource, `mirv_agr`, SFM scripts, and the `afxGameRecord` format: <https://github.com/advancedfx/advancedfx> and <https://github.com/advancedfx/afx-sfm-scripts>. HLAE is not redistributed in this bundle; install a current official release separately. The setup GUI downloads `advancedfx_import_gameRecord.py` from the upstream AdvancedFX repository into the selected SFM installation.

No HLAE binary or AdvancedFX Python file is redistributed in this bundle. The GUI downloads the required Python file from the upstream repository during setup; review the upstream license and source before use.
