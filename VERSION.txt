TF2 STV to SFM retail HLAE capture pipeline
Bundle version: 0.7.0
Primary animation path: retail TF2 x64 + HLAE AfxHookSource mirv_agr
Required HLAE: 2.189.0 or newer
Capture rate: 30 fps
SFM transport: afxGameRecord

Verified in the build environment:
- The original Rust parser source and complete JSON export remain bundled.
- The launcher generates one Source VDM containing exact start/stop PlayCommands for every non-overlapping batch range.
- Batch capture uses one retail TF2/HLAE process and writes a separate validated AGR into each clip folder.
- mirv_agr is enabled before playdemo and records camera, players, weapons, projectiles, invisible entities, and persistent ragdolls.
- The HLAE custom-loader interface is invoked noninteractively with tf_win64.exe and the x64 AfxHookSource.dll.
- Launch arguments always include -insecure and +sv_lan 1; generated commands contain playdemo and never contain connect or matchmaking.
- TF2 console output and AGR size progress are streamed to the terminal.
- The resulting AGR header and version are validated before success is reported.
- A backup-first SFM gameinfo tool mounts the user's current TF2 `tf` VPKs and loose content, with a restore BAT.
- Mount hotfix: writes BOM-free UTF-8 KeyValues and uses normalized forward-slash paths; older SFM parsers reject a PowerShell UTF-8 BOM.
- Recovery hotfix: restore scripts explicitly select the newest timestamped gameinfo backup and include an emergency restore BAT.
- The GUI installs and validates the AdvancedFX `advancedfx_import_gameRecord.py` SFM rig in the selected SFM installation.
- Packaging fix: the downloadable bundle retains the parser `src\\bin` source files required to build `export_all.exe`.

Requires user-side verification:
- Current retail TF2 can play the supplied demo and has the exact map/content it references.
- HLAE is current enough for TF2 x64 and hooks successfully on the user's installation.
- A short SFM import visibly animates players.
